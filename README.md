# منصة المعهد الفني الصناعي بالإسكندرية (ITI Alex Hub)

منصة أكاديمية طلابية حديثة ومتكاملة مبنية بـ **Next.js 15 (App Router)**، **Tailwind CSS**، **Supabase (PostgreSQL)**، و **Telegram Bot API**. تجمع المنصة كافة الشعب الـ 7 للمعهد الفني الصناعي بالإسكندرية في واجهة واحدة متطورة وسريعة بدون الحاجة لتسجيل دخول للطلاب.

---

## 🏛️ الشعب الدراسية المدعومة (7 شعب)
1. **شعبة المساحة العامة والخرائط** (General Surveying)
2. **شعبة العمارة والإنشاءات المدنية** (Architecture & Civil Construction)
3. **شعبة الشبكات والآلات الكهربية** (Electrical Networks & Machines)
4. **شعبة الأجهزة الإلكترونية والحاسبات** (Electronics & Computers)
5. **شعبة تكنولوجيا التبريد وتكييف الهواء** (Refrigeration & Air Conditioning)
6. **شعبة التشغيل والتشكيل وتكنولوجيا الإنتاج** (Machining, Forming & Mechanics)
7. **شعبة تكنولوجيا ميكانيكا وكهرباء السيارات** (Automotive Mechanics & Electricity)

---

## 🚀 المراحل الخمسة المنفذة بالكامل

### 1. المرحلة الأولى: قاعدة البيانات وهيكل الجداول (Database & Storage)
- **ملفات SQL:**
  - `supabase/schema.sql`: تعريف الجداول الستة (`departments`, `subjects`, `resources`, `schedules`, `announcements`, `admins`) مع الفهارس وسياسات الأمان (RLS) التي تتيح القراءة العامة للطلاب وتقييد التعديل للأدمن.
  - `supabase/seed.sql`: بيانات أولية واقعية للشعب الـ 7، مع تفاصيل مذكرات وشيتات ومحاضرات وجداول كاملة لشعبة المساحة العامة وباقي الشعب.
- **ملفات الاتصال:**
  - `types/database.ts`: تعريفات TypeScript متوافقة تماماً.
  - `lib/supabase.ts`: عميل Supabase الآمن مع وضع التوافق التلقائي.
  - `lib/dataService.ts`: طبقة بيانات ذكية تعمل محلياً ببيانات تجريبية حتى قبل ربط قاعدة البيانات، وتتحول تلقائياً إلى Supabase فور إدخال المفاتيح.

### 2. المرحلة الثانية: الهوية البصرية وواجهة الطالب (Student Academic Hub)
- تصميم احترافي داكن عالي التباين (High-Contrast Dark Mode) بألوان متناسقة:
  - الخلفية: `#070B14`
  - الكروت: `#0F172A`
  - الحدود: `#1E293B`
  - درجات التمييز: السماوي `#06B6D4` والأخضر الزمردي `#10B981`
- شريط ذكي لاختيار الشعبة، الفرقة (الأولى/الثانية)، الترم، والسكشن مع حفظ الاختيار تلقائياً في `localStorage`.
- قسم استعراض التلخيصات والشيتات مع بحث فوري، فلترة بالمادة والنوع، وحفظ في المفضلة.
- نافذة قراءة ومذاكرة متقدمة (`StudyReaderModal`) تدعم الشرح المنسق، القوانين الرياضية، نسخ النصوص، والطباعة، وتحميل ملفات PDF الأصلية.

### 3. المرحلة الثالثة: نظام الجداول والسكاشن ومواعيد التسليم (Schedules & Deadlines)
- تبويب الجداول التفاعلية:
  - تحديد يوم اليوم الحالي تلقائياً باللغة العربية.
  - فلاتر الأيام، أرقام السكاشن (عام، سكشن 1 إلى 4)، ونوع الفترة (محاضرة نظري، سكشن عملي، ورشة، معمل).
  - توضيح توقيت البداية والنهاية، اسم القاعة أو المعمل، واسم المحاضر.
- تبويب مواعيد التسليم والتنبيهات:
  - عدّاد تنازلي فوري (باقي 2 يوم، عاجل غداً، منتهي).
  - شريط تنبيهات عاجل (`UrgentBanner`) في أعلى الموقع.

### 4. المرحلة الرابعة: لوحة تحكم الأدمن ومناديب الشعب (`/admin`)
- نظام تسجيل دخول بصلاحيات:
  - **Super Admin** (إشراف كامل على كل الشعب وإدارة عامة).
  - **Department Rep** (مندوب شعبة محددة مثل مساحة عامة).
- 4 وحدات متكاملة:
  1. نشر تلخيص / شيت / بنك أسئلة جديد مع دعم تفاصيل الشرح وتاريخ التسليم.
  2. إدارة وتحديث جدول المحاضرات والسكاشن وحذف/إضافة الفترات.
  3. نشر تنبيهات إدارية وعاجلة تظهر فوراً للطلاب.
  4. استعراض المحتوى وإمكانية تصدير واستيراد نسخة احتياطية كاملة بصيغة JSON.

### 5. المرحلة الخامسة: إشعارات التليجرام التلقائية والـ PWA والنشر
- مسار API للإشعارات التلقائية: `/api/notify-telegram` يرسل رسائل منسقة بصيغة HTML لجروبات وقنوات الدفعة على تليجرام عند نشر أي شيت أو ملخص جديد.
- دعم PWA مع ملف `manifest.json` وأيقونات التطبيق للتثبيت على هواتف الطلاب كأيقونة تطبيق رئيسية.
- إعداد كامل للمشاركة على السوشيال ميديا (OpenGraph & Twitter Cards).

## 💻 طريقة التشغيل محلياً

```bash
# 1. تثبيت الحزم (تم بالفعل)
npm install

# 2. تشغيل سيرفر التطوير المحلي
npm run dev
```

افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

- واجهة الطلاب: [http://localhost:3000](http://localhost:3000)
- لوحة تحكم الأدمن والمندوبين: [http://localhost:3000/admin](http://localhost:3000/admin)

## 🗄️ إعداد Supabase (اختياري)
عندما ترغب بربط قاعدة بيانات Supabase سحابية حية:
1. افتح مشروعاً على [supabase.com](https://supabase.com).
2. من تبويب **SQL Editor**، انسخ محتويات `supabase/schema.sql` واضغط **Run**.
3. ثم انسخ محتويات `supabase/seed.sql` واضغط **Run**.
4. أضف المفاتيح في ملف `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJh...
   ```
